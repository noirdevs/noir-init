# Noir Quality

Apply KISS, YAGNI, DRY, SRP, explicitness, avoidance of premature abstraction/optimization, and the Boy Scout Rule as judgment heuristics.

DRY means extract when behavior is stable and abstraction reduces complexity. KISS means the simplest design that remains correct and maintainable.

Do not rewrite correct code merely for personal style. Review complexity, abstraction stability, failure modes, dependency cost, test value, and architecture consistency.

Then STOP.
